# Pre-Match Assessment of Cricket Players Form Index

Timestamped pre-match Form Index records — one folder per match, committed
**before** first ball. The git history is the timestamp: compare a record
with the actual match result afterwards to check accuracy.

## Current record

- `india-afg-3rd-t20i-2026-09-17` — India vs Afghanistan, 3rd T20I,
  Arun Jaitley Stadium Delhi, 19:30 IST. Files:
  - `.png` — the graphical index (both playing XIs)
  - `.json` — the same numbers, machine-readable
  - `.md` — playing-XI tables
  - `.html` — static render source of the graphic (bars only, no logic)

## Reading a record

- **Index 75+ (strong)** — claim of favourable timing for that player.
- **Index under 47 (caution)** — claim of a difficult outing.
- **47–74 (neutral)** — deliberately no call, neither good nor bad.
- Claims are checked after the match across batting, bowling **and**
  fielding (a catch / run-out / stumping counts as a contribution).

## What is NOT in this repo

By design: no code, no methodology, no model details. Only the final
published numbers.
